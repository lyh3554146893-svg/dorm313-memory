# 313 · 四年，留在这里

这是一间根据大学宿舍影像重建的三维房间。它保留「门口、床帘、我的床、回望、阳台、全景」六个视角，也支持鼠标、触屏和键盘漫游。

访问地址：[走进 313](https://lyh3554146893-svg.github.io/dorm313-memory/)

六个床位、蓝色床帘、阳台边的小桌，以及露天阳台外的两排树木和道路。尺寸和被遮挡处根据影像估算。

## 关于这个网站

- 静态文件托管没有后台服务；访客访问托管平台，不会连接你的桌面电脑。发布以后不用让电脑一直开着，也不用开放电脑端口。
- 这份网站没有登录、表单、数据库、统计代码、广告或第三方 CDN。脚本、样式和三维模型都从同一个网站地址加载。
- 公开网站里的三维模型可以被访客下载保存。不要把你不愿公开的照片、个人信息或其他文件一起上传。
- 页面里的 `noindex,nofollow` 和 `robots.txt` 用来劝告搜索引擎不收录；它们不是访问控制，不能阻止拿到链接的人访问，也不能保证不被收录。
- 网页设置了内容安全策略来限制资源来源。这能缩小网页自身的风险，但不是绝对安全承诺；GitHub 账号仍应使用独立密码和双重验证。
- GitHub 作为托管平台可能按照其服务规则处理访问日志；本网站没有另行安装访客统计。

## 用 GitHub Pages 分享

本网站使用 `lyh3554146893-svg/dorm313-memory` 仓库。下面的步骤也适用于复制部署这份网站：

1. 登录 GitHub，创建一个名为 `dorm313-memory` 的仓库。选择公开仓库意味着仓库文件也能被任何人查看。
2. 只上传本文件夹里的部署文件，保证 `index.html` 和 `assets` 文件夹直接位于仓库最外层。不要再套一层「313_GitHub网站」，也不要上传原始照片、视频或整个电脑工作目录。
3. 上传本文件夹内的 `.nojekyll`、`robots.txt`、`404.html`、README 和许可证文件。若网页上传器没有显示 `.nojekyll`，可以在仓库中新建这个同名空文件。
4. 打开仓库的 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，再选择 **main** 和 **/(root)**，点击 **Save**。无需另外配置工作流。
5. 等 GitHub Pages 显示发布完成，再打开它提供的地址。如果仓库名未变，示例地址是 `https://lyh3554146893-svg.github.io/dorm313-memory/`。这个地址在发布前不会自动存在。
6. 先自行打开网站，试试六个视角和漫游，再把完整链接发给朋友。

这是面向公开静态托管的版本，不含密码保护。要停止公开访问，可以在仓库 Settings → Pages 中取消发布。

## 文件说明

- `index.html`：网页入口。
- `assets/room313.glb`：三维场景，内含贴图。
- `assets/app.js`、`assets/style.css`：页面交互与外观。
- `assets/favicon.svg`：本地随附的 313 网页图标。
- `assets/three.min.js`、`assets/GLTFLoader.js`、`assets/OrbitControls.js`：本地随附的 Three.js 浏览库；原始许可证注释已保留。
- `THIRD_PARTY_LICENSES.txt`：上述第三方库的 MIT 许可证。
- `404.html`：地址不存在时的提示页面。
- `robots.txt`：不收录提示。
- `.nojekyll`：让托管平台直接提供这些静态文件。

## 本地预览或以后更新

这个版本通过 HTTP 加载模型，直接双击 `index.html` 可能被浏览器的本地文件限制拦住。日常离线查看请使用单独提供的「313_自由漫游.html」。如需预览网站，可在本文件夹运行 `python -m http.server 8000 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8000/`。这个命令只监听当前电脑。

更新场景时重新生成这份部署文件夹，再把发生变化的文件上传到同一个仓库。首次打开需要下载三维模型，网速较慢时请稍等。
